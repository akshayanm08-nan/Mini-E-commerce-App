# Mini-E-commerce-App
A responsive mini e-commerce web app featuring dynamic product cards, interactive shopping cart, real-time item count, automatic price calculation, and a modal checkout preview using HTML, CSS, and JavaScript.
🛍️ Mini E-Commerce App

A modern, responsive mini e-commerce web application built using HTML, CSS, and JavaScript. Users can browse products, add items to their shopping cart, view the total price, and preview their order through an interactive checkout modal.

✨ Features

- 🛒 Dynamic product rendering using JavaScript objects
- ➕ Add products to the shopping cart
- 🔢 Real-time cart item count
- 💰 Automatic total price calculation
- 🗑️ Remove products from the cart
- 🧾 Interactive checkout preview modal
- 📱 Responsive design for mobile and desktop
- ⚠️ Empty cart handling
- 🎨 Modern UI with smooth hover effects
- 🔒 Demo checkout without collecting payment or card details

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Arrays and Objects
- Event Handling

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Browse the available products.
5. Click Add to Cart to add products.
6. Review your cart and total price.
7. Click Checkout to preview your order.

⚙️ How It Works

Dynamic Product Rendering

Product details are stored as JavaScript objects and displayed dynamically on the webpage.

Shopping Cart

Users can add products and remove items. Each product is identified by its unique product ID.

Price Calculation

Product prices are stored as numbers. The application calculates the cart total automatically and formats the values as currency for display.

Checkout Preview

A modal displays the selected products, quantities, and total amount before the user completes the demo checkout process.

Empty Cart Handling

The application handles an empty cart and updates the item count and total when products are removed.
